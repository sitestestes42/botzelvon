# BotZelvon Geoapify V5.1

Correção do botão **Preparar mensagem**.

## Mudanças
- Preparar mensagem funciona mesmo quando a Geoapify não retorna telefone.
- O modal agora possui um campo editável de WhatsApp.
- Se houver telefone público, ele é preenchido automaticamente.
- Se não houver, a mensagem ainda pode ser preparada/copieda.
- Você pode colar manualmente um número comercial e então abrir o WhatsApp.
- O envio continua manual.
- Integração NATIVA permanece ativa para açaiterias/sorveterias/sobremesas.
